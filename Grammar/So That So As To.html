💡 Key Concepts

  • When to use: Express purpose, reason, or result
  • Three different structures:
    • "so" - Shows result/consequence (connects two clauses)
    • "so that" - Shows purpose/intention (with subject + verb)
    • "so as to" - Shows purpose/intention (formal, with infinitive)
  • Structure:
    • Clause 1, so + clause 2 (result)
    • Action + so that + subject + modal + verb (purpose)
    • Action + so as to + infinitive (formal purpose)
  • Reminders:
    • "So" = result: cause + so + result
    • "So that" = purpose: action + so that + purpose (subject + verb)
    • "So as to" = purpose: action + so as to + infinitive (formal)
    • "So that" can use modal verbs (can, will, could, would)

📋 Formation Rules

Structure Pattern Example
SO (result) Clause 1, so + clause 2 I was tired, so I went to bed early.
SO THAT (purpose) Clause 1 + so that + subject + verb I study hard so that I can pass the exam.
SO AS TO (purpose - formal) Clause 1 + so as to + infinitive She arrived early so as to get a good seat.

📖 Examples by Type

1. "SO" - Showing Result/Consequence

  • It was raining, so we stayed inside.
  • I forgot my wallet, so I couldn't buy lunch.
  • The movie was boring, so we left early.
  • He studied hard, so he passed the test.

2. "SO THAT" - Showing Purpose/Intention

  • I set an alarm so that I won't be late.
  • She speaks slowly so that everyone can understand.
  • They saved money so that they could buy a car.
  • He whispered so that nobody would hear him.

3. "SO AS TO" - Showing Purpose (Formal)

  • She left early so as to avoid traffic.
  • He took notes so as to remember everything.
  • We booked in advance so as to get better prices.
  • They arrived early so as to prepare the room.

🔄 Comparing the Three Structures

Type Meaning Formality Example
so Result/Consequence Informal/Neutral I was hungry, so I ate something.
so that Purpose/Intention Neutral I eat healthy food so that I can stay fit.
so as to Purpose/Intention Formal I eat healthy food so as to stay fit.
in order to Purpose/Intention Formal (alternative) I eat healthy food in order to stay fit.

🎯 "So That" with Modal Verbs

Modal Verb Meaning Example
can ability/possibility I study English so that I can travel abroad.
will future certainty She works hard so that she will succeed.
could past ability/possibility He saved money so that he could buy a bike.
would past intention They left early so that they would arrive on time.
won't future negative I lock the door so that nobody will enter.

⚠️ Common Mistakes

❌ Incorrect ✅ Correct
I study hard so that pass the exam. (missing subject) I study hard so that I can pass the exam.
She left early so as to she could avoid traffic. (wrong structure) She left early so as to avoid traffic.
I was tired so that I went to bed. (wrong connector) I was tired, so I went to bed.
He whispered so as to nobody would hear. (wrong verb form) He whispered so that nobody would hear.
I study English so that to travel abroad. (mixed structure) I study English so as to travel abroad.

📦 Concept Compressed

These three expressions serve different functions: so shows result, while so that and so as to express purpose. Understanding their distinct uses and structures is essential for clarity.

"So" - Result/Consequence

Pattern: Cause/Reason, so result/consequence

  • It was raining, so I took an umbrella. (result of the rain)
  • She was tired, so she went to bed early.

Note: "So" connects two independent clauses showing cause and effect.

"So That" - Purpose/Intention

Pattern: Action + so that + subject + modal verb + base verb

  • I took an umbrella so that I wouldn't get wet. (purpose)
  • She went to bed early so that she could wake up refreshed.
  • He studies hard so that he can pass the exam.

Common modals: can, will, could, would, may, might

"So As To" - Purpose/Intention (Formal)

Pattern: Action + so as to + infinitive (base verb)

  • She arrived early so as to get a good seat. (formal purpose)
  • He spoke quietly so as to avoid disturbing others.

Note: Very formal; more common in written English. Can often replace with "in order to" or "to."

Comparison Table

Expression Function Structure Example
so Result Clause, so clause I was hungry, so I ate.
so that Purpose Action so that subject + modal + verb I ate so that I wouldn't be hungry.
so as to Purpose (formal) Action so as to + infinitive I ate so as to satisfy my hunger.

Alternative Expressions for Purpose

  • In order to: She studies hard in order to pass. (formal)
  • To: She studies hard to pass. (simple, common)

Key Rules

  • "So" for results: What happened as a consequence? (It rained, so we stayed inside)
  • "So that" for purpose: Why did you do it? (We stayed inside so that we wouldn't get wet)
  • Same subject? Often use simple "to" instead of "so that" (I went to the store to buy milk)
  • Different subjects? Must use "so that" (I whispered so that she could sleep)
