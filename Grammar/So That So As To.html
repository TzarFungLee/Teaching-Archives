📦 Concept Compressed

So shows result, while so that and so as to express purpose.

Function Comparison

Connector Function Structure
so Result Cause, so result
so that Purpose Action so that subject + modal + verb
so as to Formal Purpose Action so as to + base verb

Key Rules

  • "So" for results: What happened because of something else?
  • "So that" for purpose: Why was the action taken?
  • "So as to" for formal purpose: Very common in academic writing.
