🔗 Connector Roadmap

Use to show Results & Purpose.

📉 Result
What happened?
Cause, so ...
"I was tired, so I slept."
🎯 Purpose
Why did you do it?
so that / so as to
"I study so that I can pass."

📖 Practice

Structure Example Sentence
Using "SO" (Result)
tired / went to bed I was tired, so I went to bed. 🔊
hungry / ate I was hungry, __________ (so) I ate a sandwich. I was hungry, so I ate a sandwich. 🔊
Using "SO THAT" (Purpose)
study / pass I study hard so that I can pass the exam. 🔊
saves money / buy car She saves money __________ (so that) she can buy a car. She saves money so that she can buy a car. 🔊
Using "SO AS TO" (Formal Purpose)
left early / avoid traffic She left early so as to avoid traffic. 🔊
not / wake baby They whispered __________ (so as / not) wake the baby. They whispered so as not to wake the baby. 🔊
Using "TO / IN ORDER TO" (the everyday purpose forms)
woke early / catch train I woke up early __________ (to) catch the first train. I woke up early to catch the first train. (= in order to catch it) 🔊

📦 Concept Compressed

So shows result, while so that and so as to express purpose.

Function Comparison

Connector Function Structure
so Result Cause, so result
so that Purpose Action so that subject + modal + verb
so as to Formal Purpose Action so as to + base verb
to / in order to Everyday Purpose Action to + base verb

Key Rules

  • "So" for results: What happened because of something else?
  • "So that" for purpose: Why was the action taken? Usually followed by can/could/will/would: "…so that I can pass."
  • "To / in order to / so as to": all three go straight to a base verb — to is the everyday form; in order to and so as to are formal.
  • Negative purpose: so as not to / in order not to — "I tiptoed so as not to wake anyone."
  • Choose by what follows: new subject + modal → so that; just a verb → to / in order to / so as to.
