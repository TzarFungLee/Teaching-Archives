First Conditional

💡 Key Concepts

  • When to use: Talk about real and possible situations in the future
  • Structure: If + present simple, subject + will + base verb
    • If clause (condition): Uses present simple to describe a possible situation
    • Main clause (result): Uses will + base verb to describe what will happen
    • Example: If it rains, we will stay home.
  • Reminders:
    • Never use "will" in the if-clause
    • Use a comma when the if-clause comes first
    • Can use other modals (can, may, might, should, must) instead of "will"

Formation Rules

Clause Type Structure Example
If Clause + Main Clause If + subject + present simple If you study hard
Main Clause + If Clause subject + will + base verb you will pass the exam
Complete Sentence If + present simple, will + base verb If you study hard, you will pass the exam.

📖 Examples by Category

Predictions

  • If it snows tomorrow, the schools will close.
  • If you eat too much, you will feel sick.
  • If he doesn't hurry, he will miss the bus.

Warnings

  • If you touch that hot pan, you will burn yourself.
  • If you don't wear a coat, you will get cold.
  • If we don't leave now, we will be late.

Promises and Offers

  • If you help me, I will buy you lunch.
  • If you come to the party, I will introduce you to my friends.
  • If you finish early, we will go to the cinema.

🔄 Using Other Modal Verbs

Modal Verb Meaning Example
can ability/possibility If you finish early, you can go home.
may/might possibility If it rains, we might cancel the picnic.
should advice If you feel sick, you should see a doctor.
must necessity If you want to pass, you must study harder.

⚠️ Common Mistakes

❌ Incorrect ✅ Correct
If it will rain, we will stay home. If it rains, we will stay home.
If you study, you pass the exam. If you study, you will pass the exam.
If she will come, I will go. If she comes, I will go.
We will go to park, if it is sunny. (wrong comma) We will go to the park if it is sunny. (no comma)

📦 Concept Compressed

The First Conditional expresses real and possible future situations and their likely results. It uses the Present Simple in the if clause and will (or other modals) + base verb in the main clause.

Structure

If + subject + present simple, subject + will/modal + base verb

  • If it rains, we will cancel the picnic.
  • If you study hard, you will pass the exam.

Note: The clauses can be reversed without changing meaning, but drop the comma.

  • We will cancel the picnic if it rains.

When to Use

  • Real future possibilities: If I have time, I'll visit you.
  • Predictions: If you don't hurry, you'll miss the bus.
  • Promises/threats: If you help me, I'll buy you dinner.
  • Warnings: If you touch that, you'll get burned.

Modal Variations

Instead of will, you can use other modals in the main clause:

Modal Use Example
can Ability/Permission If you finish early, you can leave.
may/might Possibility If it rains, we might stay home.
should Advice If you feel sick, you should see a doctor.
must Obligation If you want to pass, you must study.

Key Rules

  • Never use "will" in the if-clause: ❌ If it will rain... → ✓ If it rains...
  • Use comma when if-clause comes first: If you study, you will pass. (But: You will pass if you study.)
  • Use present simple (not present continuous) after if for future events
