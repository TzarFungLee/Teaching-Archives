Connectives: Because, Since, So

💡 Key Concepts

  • Because/Since: Show the reason for something (comes BEFORE the result)
  • So: Show the result of something (comes AFTER the reason)
  • Structure:
    • Reason + because/since + explanation
    • Explanation + so + result

📖 Practice

Using "because/since" Using "so"
I stayed home because I was sick. I was sick, so I stayed home.
She is happy ____________ she passed the exam. She passed the exam, ____________ she is happy.
We left early ____________ it started raining. It started raining, ____________ we left early.
He couldn't sleep ____________ he drank coffee. He drank coffee, ____________ he couldn't sleep.
They are studying hard ____________ they want good grades. They want good grades, ____________ they are studying hard.

📦 Concept Compressed

These connectives link cause and effect. Because and since introduce reasons (cause), while so introduces results (effect). The key difference is word order and which clause comes first.

Because / Since (Reason → Result)

Use when starting with the reason or when the reason is more important:

  • Because I was tired, I went to bed early.
  • Since it was raining, we canceled the picnic.
  • I stayed home because I felt sick.

Note: "Since" can also mean "from a time in the past," so "because" is clearer for reasons.

So (Reason → Result)

Use when starting with the reason and the result follows naturally:

  • I was tired, so I went to bed early.
  • It was raining, so we canceled the picnic.
  • I felt sick, so I stayed home.

Comparison

Connector Pattern Example
because Result + because + reason
Because + reason, result		 I'm happy because I passed.
Because I passed, I'm happy.
since Result + since + reason
Since + reason, result		 We left since it was late.
Since it was late, we left.
so Reason, so result I passed, so I'm happy.

Key Rules

  • Because/Since: Can start the sentence or come in the middle; use comma when starting
  • So: Cannot start a sentence; comes between two clauses with a comma before it
  • Same meaning, different structure: "I left because I was tired" = "I was tired, so I left"
